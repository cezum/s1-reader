# S-1 阅读器

一个本地离线的小工具：读美股招股书（S-1 / F-1 / 10-K 都行）时，随手把看不懂的专业词存成词条，下次在别的文件里遇到同一个词，正文会自动标黄。

单个 HTML 文件直接打开就能用，不需要联网、不需要安装、不需要构建。所有数据存在浏览器 localStorage，不上传任何服务器。

## 一、怎么打开

双击 `index.html` 就行，用 Edge 或 Chrome 都可以。

打开后把 PDF 拖进窗口，或者点左上角「打开 PDF」。

> 建议固定用同一个浏览器打开。词条和批注存在浏览器的本地存储里，换浏览器数据不互通。

---

## 二、目录与跳转

点顶栏的「目录」，右侧会列出这份文件的章节，**点一下直接跳过去**。

三种情况都能处理：

1. **PDF 自带书签** —— 直接读取，带层级缩进
2. **没有书签、但正文里有可点击的目录页** —— 会自动找到那一页（S-1 一般在开头几页），把上面的目录条目解析成章节列表，并标出每一项对应的 PDF 页码
3. **两者都没有** —— 用顶栏的页码框直接输入页码跳转

**滚动时目录会自动高亮当前章节**，读到哪儿一眼就知道自己在第几章。

另外，正文里那些蓝色的目录链接（比如每页顶部的 `Table of Contents`）现在也能点：鼠标移上去会出现浅蓝底，点一下就能回到目录页。这是 PDF 自带的链接，不是我自己加的。

> 侧栏目录识别自 PDF 自带的目录页，个别文件排版特殊时可能漏项或标题不全。遇到这种情况，直接点正文里的目录页链接也是一样的。

## 三、三个动作

读的时候，用鼠标选中一句话，会浮出三个按钮：

| 按钮 | 用途 | 什么时候用 |
|---|---|---|
| **存为术语** | 建一个词条，进术语库 | 遇到反复出现的专业词（greenshoe、VIE、liquidation preference……） |
| **写批注** | 在这段话上留想法 | 读某段有感触、有疑问、想记下商业含义时 |
| **仅高亮** | 只做标记，不写字 | 先划出来，回头再说 |

点「存为术语」后，弹窗会自动带出：

- **原词**：你选中的文字
- **出处**：文档名、页码、以及这个词出现的整句话（自动抓的，不用手抄）

需要你填的是三样：

1. **中文译名** —— 保证以后看到的是同一个译法
2. **一句话释义** —— 这是什么
3. **商业含义 / 我的理解** —— 它实际上影响什么

第三栏是最值钱的。比如 `liquidation preference`，释义只是「优先清算权」，但真正该记的是「决定退出时谁先拿钱，要看几倍、是否 participating」——这句是你自己的判断，网上查不到。

## 四、术语库怎么用

右侧「术语库」标签页，已经预置了 64 个 S-1 高频词，可以直接用。

- **搜索**：输入中英文都行，`Ctrl+F` 直接定位到搜索框
- **展开**：点一下词条，展开释义、商业含义、关联词、出处
- **跳到此页**：回到它在原文里出现的位置（仅限创建时的那份文档）
- **编辑**：随时改，改完正文的标注会立刻更新

**最重要的一个行为**：术语库里的词，只要在当前 PDF 里出现，正文就会自动标上淡黄色底纹。你扫一眼就知道「这个词我记过」，点一下还能在右侧调出词条。读到第三份 S-1 的时候，基本就不需要再查了。

## 五、阅读操作

| 操作 | 快捷方式 |
|---|---|
| 翻页 | `←` `→`，或顶栏页码框输入后回车 |
| 缩放 | `+` `−`，或顶栏按钮 |
| 打开目录 | 顶栏「目录」按钮 |
| 搜术语 | `Ctrl+F` |
| 保存弹窗 | `Ctrl+S` |
| 关闭弹窗 | `Esc` |

打开文档时会自动适配窗口宽度，手动缩放一次之后就不再自动调整。

## 六、数据在哪，怎么备份

**存在浏览器本地**（localStorage），不上传任何服务器。

⚠️ 两种情况下会丢：

1. 浏览器设置里清理了「网站数据 / Cookie 及网站数据」
2. 换了一个浏览器打开

所以请养成习惯：**每读完一份重要文件，点一次「导出 → 导出术语与批注（Markdown）」**，导出的 .md 可以直接看，也能丢进 Obsidian、Notion 或任何笔记软件。

`samples/sample-export.md` 是一份真实导出的样子，可以先看格式再决定要不要用。

- **备份数据**（JSON）：完整备份，含所有词条和批注
- **恢复**：从 JSON 备份导入，同名词条会自动跳过、只补空缺，不会覆盖你后来改的内容

## 七、常见问题

**Q：能读 F-1、10-K、港股招股书吗？**
能，任何 PDF 都行。术语库是跨文档共享的，批注按文档分开存。

**Q：扫描版 PDF（图片型）能标术语吗？**
不能。这类 PDF 没有文字层，选不中文字。需要先做 OCR。

**Q：为什么有些词没被标黄？**
两种情况：一是术语库里没有这个词；二是 PDF 把词切成了两半，程序做了相邻拼接兜底，但极端情况下仍可能漏。可以点词条的「跳到此页」确认。

**Q：目录里的章节不全怎么办？**
目录是识别 PDF 自带目录页的链接得到的。如果某份文件排版特殊导致漏项，直接翻到目录页点正文里的链接即可，效果一样。

**Q：能同步到手机吗？**
不能。这是纯本地工具。要跨设备，用导出的 Markdown。

**Q：为什么不做一个后端？**
这个工具的价值在于「零配置」——双击就开，关掉就走，不用注册、不用登录、不用担心自己的阅读记录和批注躺在别人服务器上。加后端会把这些全毁掉。

## 九、想改预置词条

打开 `terms-seed.js`，照着现有格式加就行：

```js
{ term: "earn-out", zh: "或有对价", def: "一句话释义", note: "商业含义", related: "关联词", section: "常见章节" }
```

但注意：**预置词条只在第一次打开（或清空数据后）时写入**。已经用过之后改这个文件不会生效，直接在界面里增删改更快。

## 十、实现上几个不太显然的选择

记在这里，免得以后有人（包括我自己）以为是随手写的。

**术语库和批注的归属不一样。** 术语是知识，应该跨文档复用；批注是对某一份文件的具体段落说的，离开那份文件就没意义。所以术语全局共享，批注按文档名归属。

**批注锚点用归一化字符索引，不用选区 DOM。** 缩放、重绘文本层之后 DOM 节点全变了，靠选区恢复位置会漂移。改成记「这句话在归一化文本里的第几个字符」，重绘后重新映射回去，位置就稳。

**术语命中同时做 span 内匹配和相邻 span 拼接。** PDF 的文字层经常把一个词切成好几个 span（比如 `green` + `shoe`），只按 span 内正则匹配会漏掉大量词。所以先做 span 内匹配，再把相邻 span 的文本拼起来匹配一次。

**PDF 引擎本地优先、CDN 兜底。** `libs/` 里放了 pdf.js 的完整构建，离线可用；本地加载失败时才回落到 cdnjs / jsdelivr。这是为了守住「不联网也能用」。
